# 开发工具包 · JSON 工具模块 — 需求文档

> 版本：v0.3（本期）  
> 日期：2026-08-12  
> 状态：已实现  
> 公共部分（导航 / 界面语言 / 响应式 / 非功能需求）见 [公共需求](./公共需求.md)

## 1. 模块定位

面向开发者的本地 JSON 处理工具（`/json`），覆盖格式化 / 压缩 / 校验 / 结构对比 / 类型转换等高频场景，处理过程不离开浏览器。

**核心目标：**

- 精确报错：自研严格 JSON 解析器（兼容标准 JSON 全部语法），语法错误可定位到行列并展示出错位置上下文（现代 V8 的 `JSON.parse` 错误信息不含位置，无法满足需求）。
- 连续处理：格式化 / 压缩结果直接写回输入框，便于反复处理；对比结果按路径勾选后复制 / 下载。
- 开发者友好：支持 JSONC/JSON5 宽松模式、重复键与超安全整数范围（2^53）大数检测、一键生成 TypeScript 接口。

## 2. 功能需求

### 2.1 三种模式

- 页签切换：**格式化校验** / **对比** / **类型转换**。
- 格式化校验与对比为手动触发（点击按钮或 `Ctrl/Cmd + Enter`）；类型转换输入后自动生成（防抖 250ms）。
- 输入草稿通过 zustand 挂在路由之上：切换工具不丢数据，刷新浏览器后重置。

### 2.2 格式化校验（处理模式）

- 三种动作：**格式化** / **压缩** / **校验**。
- 格式化：缩进 2 或 4 空格可选；可开启排序键（对象键按字典序递归排序）；结果写回输入框。
- 压缩：紧凑输出（无多余空白）；结果写回输入框。
- 校验：输出“JSON 合法”或报错（行列 + 出错位置上下文，错误行在编辑器中高亮）；展示大小与行数。
- 重复键检测：列出键名与首次 / 再次出现的行号。
- 大数提示：检测超出 2^53 安全整数范围的整数字面量并提示可能丢失精度。
- 宽松模式（JSONC/JSON5）：允许注释、尾逗号、单引号、无引号键；宽松模式下输出仍为标准 JSON，重复键 / 大数不检测。
- 自动解包默认开启：输入是“字符串里套着 JSON”（如日志中带引号的 JSON）时按内层 JSON 处理。

### 2.3 对比

- 修改前 / 修改后两个输入区：可导入文件、加载示例、交换两侧、一键开始对比。
- 结构 diff：对象按字段递归比较；数组按下标对齐（v0 不做 LCS 重排）；变更类型为新增 / 删除 / 修改，展示路径与前后值。
- 对比前自动把两侧规范化后写回编辑器；两侧完全一致时明确提示。
- 结果按路径勾选，默认全选；复制 / 下载仅输出选中的差异项，未选中时弹框提示。

### 2.4 类型转换

- 由 JSON 结构生成 TypeScript 接口，便于直接粘贴到代码中使用。
- 自动解包字符串内嵌 JSON；数组取首个元素推断元素类型（空数组输出 `unknown[]`）。
- 命名规则：根接口为 `Root`，嵌套对象按“父接口名 + 字段名”命名，重名自动追加序号；非法字段名加引号。

### 2.5 编辑器与通用能力

- 处理模式输入框基于 CodeMirror 6：JSON 语法高亮、代码折叠、`Ctrl+F` 搜索与匹配计数、错误行高亮、跟随全局深浅色主题。
- 导入 `.json` 文件（单文件 ≤ 5MB，超限忽略并提示）、加载示例、一键清空。
- 复制 / 下载：`formatted.json`、`minified.json`、`json-report.txt`（校验报告）、`json-diff.txt`（对比报告）、`types.txt`（类型定义）。
- 全部处理在本地浏览器完成，无网络请求。

## 3. 验收标准

1. 粘贴 JSON 执行格式化：缩进与排序键生效，结果写回输入框且可复制 / 下载；非法 JSON 报错可定位到具体行。
2. 校验模式：重复键给出首次 / 再次出现行号；2^53 以上大数给出警告；宽松模式可解析 JSONC 并输出标准 JSON。
3. 对比模式：增删改均按路径列出，复制 / 下载内容只含勾选差异项；两侧一致时提示无差异。
4. 类型转换：嵌套对象 / 数组生成可直接粘贴到 TS 文件的接口，无语法错误。
5. 断网状态（构建产物本地打开）全部功能可用，处理过程无任何网络请求。
