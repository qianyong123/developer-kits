# 砺 · SVG 压缩模块 — 需求文档

> 版本：v0.2（已实现）  
> 日期：2026-08-08  
> 状态：已实现  
> 公共部分（导航 / 界面语言 / 响应式 / 非功能需求）见 [公共需求](./公共需求.md)

## 1. 模块定位

面向前端开发者的独立 SVG 优化工具（`/svg`）。与位图压缩不同，SVG 是矢量文本，优化目标是结构/精度层面的“无损瘦身”，不简化几何形状、不改变渲染结果。

## 2. 功能需求

- 拖拽 / 点击导入 `.svg` 与 `.svgz`（gzip 自动解压），单文件上限 20MB，可多选。
- 三档压缩强度：
  - **高保真**：仅结构清理（注释、编辑器元数据、冗余属性、合并路径等），坐标精度保留 3 位小数。
  - **平衡（默认）**：坐标精度 2 位 + 多轮优化，视觉上无损。
  - **极限**：额外尝试单色渐变转换、路径复用等进阶优化，自动选取两种方案中体积更小的结果（保证不劣于平衡档）。
- 输出格式：`.svg` 或 `.svgz`（gzip 压缩，适合存储/传输；网页中浏览器通常已自动 gzip）。
- 文件名规则：默认在原名后追加 `-compressed` 后缀（如 `icon.svg` → `icon-compressed.svg`），避免与原文件同名；支持自定义前缀 / 后缀，均留空时保持原文件名（格式转换仅更换扩展名）。
- 批量处理与进度、汇总压缩率、一键 ZIP 打包下载（ZIP 层对 SVG 文本启用压缩）。
- 单张下载与“保留原文件”策略：优化结果不小于原文件时保留原文件并标注。
- 对比预览：滑动视觉对比 + 优化后源码查看与复制。
- 全部处理在本地浏览器完成，无网络请求。

## 3. 验收标准

1. 拖入 10 个混合 SVG 文件（含 svgz），全部成功且结果 ≤ 原文件体积。
2. 极限档对含重复路径的文件，结果 ≤ 平衡档结果（路径复用生效或取小）。
3. 对比弹窗中视觉对比与源码查看均可用；复制按钮可复制优化后代码。
4. ZIP 下载可正常解压，文件名与输入保持一致，格式转换时仅更换扩展名（`x.svg` → `x.svg` / `x.svgz`）。
5. 断网状态下（构建产物本地打开）全部功能可用，处理过程无任何网络请求。
