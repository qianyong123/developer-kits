# 砺 Hone — 公共需求

> 版本：v0.3（草案）  
> 日期：2026-08-12  
> 状态：待评审
> 适用范围：所有模块（图片压缩、SVG 压缩、JSON 工具等）

## 1. 项目概述

面向前端开发者（最终面向所有普通用户）的纯本地开发者工具集“砺”。用户上传本地文件，在浏览器内完成处理（压缩、转换、校验等），全程不需要上传服务器，保护隐私的同时免去后端成本。

**核心目标：**

- 所有处理在浏览器本地完成，零上传、零后端，可离线使用。
- 以长期可维护的 React 工程起步，按模块扩展不同开发工具。
- 每个模块独立成页（`/image`、`/svg`、`/json` …），共享外壳、批量队列、下载、对比预览等公共设施。

## 2. 公共需求

### 2.1 工具包导航

- 应用采用工具包式布局：侧边导航，各工具独立路由。
- 当前入口：图片压缩（`/image`，默认首页）、SVG 压缩（`/svg`）、JSON 工具（`/json`）。

### 2.2 界面语言

- 使用中文界面；文案统一收敛到语言资源文件，为后续多语言（i18n）预留，不在组件中硬编码。

### 2.3 响应式适配（PC / 移动端）

- 桌面端（≥1024px）：多列卡片网格 + 侧边设置面板，适合批量操作。
- 移动端（<768px）：单列布局，设置面板改为可折叠/抽屉式；拖拽区降级为“点击选择”（移动端拖拽不便）；按钮、滑块采用触控友好的尺寸。
- 对比预览同时支持鼠标拖拽分割线和触摸滑动。
- 目标浏览器：桌面 Chrome / Edge / Safari / Firefox；移动端 iOS Safari / Android Chrome。

### 2.4 非功能需求

- **性能**：大文件处理不导致页面卡死；批量处理不阻塞 UI（异步 + 并发控制 / Web Worker）。
- **隐私**：除浏览器自身能力外，不发起任何网络请求；可离线使用（构建后静态部署）。
- **兼容性**：最新版 Chrome / Edge / Safari / Firefox；移动端 iOS Safari / Android Chrome 为正式支持场景，与 PC 同等对待。
- **可维护性**：TypeScript 类型覆盖核心逻辑；处理逻辑与 UI 分离，便于单元测试和新增工具。
- **体积**：首屏产物尽量精简；重型依赖按需加载（动态 import / Worker chunk），不引入非必要依赖。

### 2.5 预览背景（透明区域）

- 预览背景**自动选择**，无需用户设置：图片 / SVG 实际含透明像素时，卡片缩略图与视觉对比弹窗使用**棋盘格**背景；完全不透明时使用**白色**。
- 检测口径统一：各工具行为一致；JPEG 等无 alpha 通道的格式直接视为不透明。

## 4. 已确认决策与遗留问题

**已确认：**

- 界面语言：中文界面，文案走统一资源文件，预留 i18n。
- 元数据（图片模块）：提供“保留元数据”开关，默认关闭（与 TinyPNG 网页版一致）；开启后仅 JPEG 完整支持，WebP / PNG 输出不支持。
- SVG 压缩：不启用几何简化（路径抽稀），三档均为视觉无损；极限档双方案取小。
- JSON 工具：自动解包（字符串内嵌 JSON）默认开启；宽松模式（JSONC/JSON5）可选，输出仍为标准 JSON；结构对比数组按下标对齐，不做 LCS 重排；类型转换按首个元素推断数组类型，空数组输出 `unknown[]`。
- AVIF 支持（图片模块）：已决策不做，不引入 WASM 编码器。
- 文件名规则（图片 / SVG 模块）：默认追加 `-compressed` 后缀，支持自定义前缀 / 后缀，均留空时保持原文件名。

**遗留：**

- 记录/导出历史压缩记录：当前不在范围内，后续再议。
- 部署：前端已通过 CloudBase 静态托管上线（版本化部署、手动触发）；暂使用平台默认域名，自有域名与备案暂不考虑。
