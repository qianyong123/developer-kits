# 开发工具包 · 图片压缩模块 — 需求文档

> 版本：v0.1（本期）  
> 日期：2026-08-06  
> 状态：待评审  
> 公共部分（导航 / 界面语言 / 响应式 / 非功能需求）见 [公共需求](./公共需求.md)

## 1. 模块定位

面向前端开发者的网页版图片压缩工具，是“开发工具包”系列的第一个工具。用户上传本地图片，在浏览器内完成压缩、格式转换和批量下载。

**核心目标：**

- 在浏览器本地完成所有图片处理，零上传、零后端。
- 提供“体积最小”和“保真优先”两种压缩思路，由用户按场景选择。
- 支持批量处理与格式转换（WebP / JPEG / PNG），一键打包下载。

### 1.1 目标用户与使用场景

| 用户 | 场景 |
| --- | --- |
| 前端开发者 | 提交代码前压缩素材图、给页面/小程序准备 WebP 图 |
| 设计师/运营 | 把大图压到指定体积（如 <200KB）用于投稿或上传 |
| 普通用户 | 批量压缩手机照片，转成更通用的格式 |

## 2. 功能需求

### 2.1 图片导入

- 支持拖拽多张图片到页面，也支持点击选择文件（`<input type="file" multiple>`）。
- 支持格式：JPEG / PNG / WebP / GIF（静态帧）/ BMP。
- 单文件大小上限 100MB、尺寸上限 16384px 或 1 亿像素，超限文件忽略并提示。
- GIF 动图仅保留第一帧并转为 PNG（检测到动画时在卡片上提示）。
- 支持随时追加图片、移除单张、清空列表。

### 2.2 两种压缩模式

**模式一：手动质量模式（保真优先）**

- 全局质量滑块（10–100，步进 1），作用于所有待处理图片。
- 实时预览：滑块变化后立即重新压缩并更新预览图与体积数据。
- 提供原图 / 压缩图对比（并排或滑动对比），可放大查看细节。

**模式二：目标体积模式（体积最小）**

- 用户输入目标大小（KB），程序自动在质量范围内二分搜索，找到“不超过目标体积的最大质量”。
- 对 JPEG / WebP 调整 quality 参数；对 PNG 先尝试格式转换策略（见 2.3）。
- 若某张图即使最低质量仍大于目标体积，明确提示“无法达标”，并给出最低质量下的实际体积。
- 允许用户为“无法达标”的图设置处理策略：继续用最低质量输出 / 保持原图 / 丢弃。

### 2.3 格式转换

- 输出格式选项：**原格式（默认，与上传格式一致，同 TinyPNG）**、WebP、JPEG、PNG。
- “原格式”下 JPEG / WebP / PNG 按原格式输出；GIF / BMP 不支持原格式输出，自动转为 PNG 并在卡片上提示。
- 选择 JPEG / WebP 时支持透明背景处理策略：填充白色 / 填充指定色 / 拒绝转换并提示。
- **AVIF 不在 v0.1 范围**，但编码器接口按可插拔设计，v0.2 接入 WASM 编码器即可支持。

### 2.4 PNG 压缩策略

- PNG 输出**始终使用有损量化**（调色板量化，近似 TinyPNG 思路）：24 位真彩色转为 8 位索引色，每个颜色自带 alpha（支持半透明渐变/光晕）。
- 手动质量模式（保真优先）下，质量滑块映射为调色板颜色数（16–256 色），**不做**自适应减色；目标体积模式（体积最小）下对颜色数做二分搜索，并允许自适应减色。
- 尺寸缩放（降采样，默认最大边长 4096px）始终生效。
- 推荐策略提示：追求更小体积可转换为 WebP / JPEG。

### 2.5 批量处理与进度

- 图片以列表/卡片形式展示，每张包含：缩略图、文件名、原图大小、压缩后大小、压缩率、状态。
- 批量处理队列支持并发控制（默认同时处理 2–3 张，避免浏览器卡死）。
- 处理进度以“已处理 x / 总数”和单张状态（待处理 / 处理中 / 完成 / 失败）展示。
- 失败原因可见（格式不支持、无法解码、内存不足等），失败不阻塞其他图片。
- 重新压缩：全局参数变化后，一键“重新压缩全部”。

### 2.6 下载

- 单张下载：点击图片卡片上的下载按钮。
- 批量下载：全部压缩结果打包为 ZIP 一键下载。
- 文件名规则：`原文件名.输出格式`，若与原格式相同则追加 `-compressed` 后缀；支持后续扩展重命名规则。
- 若压缩结果大于原图，自动保留原图作为结果并标注“原图已是最优”，避免输出更大的文件（GIF/BMP 转 PNG 场景除外）。

### 2.7 元数据与隐私

- 提供“保留元数据”开关，**默认关闭**（与 TinyPNG 网页版一致：默认剥离 EXIF 等元数据，体积更小、更私密；需要存档时可手动开启）。
- 保留开启时，解析原图元数据并写入压缩结果：仅 JPEG 支持；WebP / PNG 不支持，UI 上如实标注。
- 页面明示“所有处理均在本地浏览器完成，图片不会上传”。

## 3. 验收标准

1. 拖入 10 张混合格式图片，批量转 WebP 后全部成功，ZIP 可正常解压。
2. 目标体积模式下，JPEG/WebP 图片在目标体积可达范围内，结果 ≤ 目标值（允许 ±5% 容差）。
3. 单张 10MB 图片处理过程中页面可交互，处理完成时间可接受（≤ 5 秒量级，视机器而定）。
4. 断网状态下（构建产物本地打开或静态托管）全部功能可用。
5. 处理过程无任何网络请求（DevTools Network 面板验证）。
6. 在 375px 宽（手机）与 1280px 宽（桌面）视口下，核心流程（导入 → 压缩 → 下载）均可完成且无布局溢出。
